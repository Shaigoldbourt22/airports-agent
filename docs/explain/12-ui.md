# 12. The UI

`static/` — three files, no framework, no build step, no `node_modules`. Plain
HTML, CSS and JavaScript served straight by FastAPI.

What it does:

**Chat.** A message list and a textarea that grows as you type. Enter sends,
Shift+Enter makes a newline. While waiting, a typing indicator shows.

**Sidebar.** Your past sessions, newest first, each openable or deletable.
A "New chat" button clears the view and drops the session id, so the next
message starts a fresh one.

**Markdown.** The model answers with tables and bold text, so replies are
rendered through a small in-house markdown converter (`markdown.js`) rather
than pulling in a library.

**Voice.** The browser's built-in Web Speech API. Press the mic, talk, the
words land in the textarea. Where the browser supports it, recognition runs
on-device rather than sending audio to a server. If the browser has no support
at all, the button simply is not there — typing still works.

**Files.** Attach up to five images, PDFs or CSVs. The browser reads each one
as base64 and sends it with the message; Gemini sees the file directly. Chips
show what is attached, with an x to remove.

**Starter chips.** A few example questions, so a first-time visitor is not
staring at an empty box.
